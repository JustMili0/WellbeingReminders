# Wellbeing Reminders
Remember to take care of yourself!

<hr>

## Why?
People need to be reminded to drink water on a hot day, stretch out a little etc.

## Description
Wellbeing Reminders displays reminders via Minecraft's toasts;
each one is configurable in Video Settings via Sodium API<br>
<small>Technically you can also edit `config\wbreminders.properties` but like, why?</small>

### Reminders:
- Hydrate Reminder - On by default
  - Reminds to hydrate so you.. well, don't dehydrate
- Meal Reminder - Off by default
  - Reminds to take a break and eat something
- Break Reminder - On by default
  - Reminds to take a break from playing
- Sleep Reminder - Off by default
  - Reminds to go to sleep at a set hour
- Stretch Reminder - Off by default
  - Reminds to stretch a little
- Wrist Exercises Reminder - Off by default
